반납할 때 연체료를 계산해서 응답에 같이 내려주세요. 반납 기한은 대출일로부터 14일이고, 기한을 넘긴 날짜당 100원입니다. 기한 당일까지는 0원이에요. 그리고 백오피스에서 과거 건을 직접 입력하는 경우가 있어서, 대출 API와 반납 API 둘 다 날짜를 선택적으로 받을 수 있게 해 주세요. 안 보내면 오늘로요.

## API

- `POST /loans` 본문에 `"loanedAt": "2026-01-01"` 을 선택적으로 받습니다. 없으면 오늘입니다
- `POST /loans/{loanId}/return` 본문에 `{"returnedAt": "2026-01-16"}` 을 선택적으로 받습니다. 본문이나 값이 없으면 오늘입니다
- 반납 응답 → `200`, `{"loanId": "…", "returnedAt": "2026-01-16", "overdueDays": 1, "lateFee": 100}`
- 예: 2026-01-01 대출(기한 2026-01-15)
  - 2026-01-15 반납 → `overdueDays` 0, `lateFee` 0
  - 2026-01-16 반납 → 1일, 100
  - 2026-01-20 반납 → 5일, 500
