회원 등록 기능이 필요해요. 이름을 받아서 회원을 만들고, 회원 ID를 돌려주는 API를 추가해 주세요. 이름은 비어 있으면 안 됩니다.

## API

모든 API 공통 약속이에요(이후 요청에도 그대로 적용됩니다).

- 요청·응답 본문은 JSON, ID 는 UUID 문자열, 날짜는 `YYYY-MM-DD` 형식입니다.
- 규칙 때문에 요청을 거절할 때는 `409 Conflict` 로 답하고 본문에 `{"error": "<짧은 코드>"}` 를 넣어 주세요.
- 존재하지 않는 ID 로 요청하면 `404` 입니다.
- 지금 있는 API(`POST /books`, `POST /loans`)는 그대로 둡니다.

이번 요청:

- `POST /members` 본문 `{"name": "김민지"}` → `201`, 응답 `{"memberId": "…", "name": "김민지"}`
- 이름이 비어 있으면 `400`
- `GET /members/{memberId}` → `200`, 응답 `{"memberId": "…", "name": "김민지"}`
