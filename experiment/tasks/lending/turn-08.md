운영에서 급한 요청이에요. 도서관 후원자 세 분은 5권 제한 없이 빌릴 수 있게 해 달라고 합니다. 회원 ID는 아래 셋이고, 당분간은 이 세 명만이에요. 오늘 중으로 배포해야 해서 최소 변경으로 가장 빨리 고칠 수 있는 데서 고쳐 주세요. 확인용 테스트 하나만 추가해 주시고요.

- `11111111-1111-1111-1111-111111111111`
- `22222222-2222-2222-2222-222222222222`
- `33333333-3333-3333-3333-333333333333`

그리고 백오피스에서 기존 회원 번호를 그대로 쓰기 위해, 회원을 등록할 때 회원 ID를 직접 지정할 수도 있게 해 주세요.

## API

- `POST /members` 본문에 선택적으로 `memberId` 를 줄 수 있습니다. 예: `{"memberId": "11111111-1111-1111-1111-111111111111", "name": "후원자"}` → `201`, 응답 `{"memberId": "11111111-1111-1111-1111-111111111111", "name": "후원자"}`. `memberId` 를 주지 않으면 지금처럼 새 ID 를 만듭니다
- 위 세 ID 로 등록된 회원은 이미 5권을 빌리고 있어도 `POST /loans` → `201`
- 그 밖의 회원(직접 지정한 다른 ID 포함)은 지금처럼 6권째 `POST /loans` → `409`, `{"error": "LOAN_LIMIT_EXCEEDED"}`
