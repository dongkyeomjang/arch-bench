반납 기능을 추가해 주세요. 대출 ID로 반납 처리하면 책이 다시 대출 가능 상태가 되어야 하고, 이미 반납된 대출을 또 반납하면 거절해야 합니다.

## API

- `POST /loans/{loanId}/return` → `200`, 응답 `{"loanId": "…", "returnedAt": "2026-01-15"}`
- 이미 반납된 대출을 다시 반납하면 `409`, `{"error": "ALREADY_RETURNED"}`
- 반납된 책은 다시 `POST /loans` 로 빌릴 수 있어야 합니다
- 반납한 대출은 5권 제한에 세지 않습니다
